# Traceability Status Legend

- `Not started`: no implementation evidence.
- `In design`: Figma/UI spec is in progress.
- `In development`: code is actively being implemented.
- `Implemented`: code exists and a developer has checked it locally.
- `Verified`: acceptance criteria passed with evidence (test report, screenshot, recording, or CI run).
- `Blocked`: dependency or product decision prevents progress.

Do not use `Verified` based on a screenshot alone for backend/security requirements.
